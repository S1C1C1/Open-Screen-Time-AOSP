The first release of Open Screen Time: screen time and parental controls for Android 14 and newer, built for GrapheneOS. **This is a test release.** Please report problems as GitHub issues.

## What it does

- **Usage dashboard:** time per app today, and a chart for the week.
- **App limits:** a daily limit per app, optionally different at weekends.
- **App groups:** put apps together so they share one daily limit, with suggested groups from app categories.
- **App schedules:** block chosen apps and groups at set times. Includes **Work or school** (8 AM–5 PM, Monday–Friday) and **Bedtime** (9 PM–6 AM) presets.
- **Downtime:** everything except always allowed apps is blocked at set times.
- **Always allowed apps:** phone, emergency calling and Settings by default.
- **Screen time PIN:** protects all settings. It's stored only as a salted hash tied to the phone's hardware keystore.
- **Restrictions (with the PIN):** app installs, developer options, adding users, and changing the date and time.
- **Private:** no internet permission. All data stays on the phone.

## Important: blocking needs a one-time setup

Installed like a normal app, Open Screen Time tracks usage and lets you set everything up, but it can only **preview** block screens.

To really block apps, it has to be made the phone's **device owner**. That needs a computer and a freshly reset phone. Follow [docs/device-owner-setup.md](https://github.com/S1C1C1/Open-Screen-Time-AOSP/blob/main/docs/device-owner-setup.md). What this mode can't protect is listed in [docs/device-owner-limitations.md](https://github.com/S1C1C1/Open-Screen-Time-AOSP/blob/main/docs/device-owner-limitations.md).

## Installing

1. On the phone, download `open-screen-time-0.1.0.apk` from the **Assets** below.
2. Open it. Android asks you to allow installs from your browser or file manager; allow it, then install.
3. **If you had a test build from GitHub Actions installed:** test builds use a different key, so Android won't install this over one.
   - Uninstall the test build first. This deletes its data.
   - If the test build is the device owner, first use Screen time → Settings → **Blocking** → **Remove device owner** (PIN).
   - Then set up device owner again for this release. That may need another factory reset.
